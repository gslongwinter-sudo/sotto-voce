# SOTTO VOCE — Issue 001

Six complete approved articles. Buildless static website; all paths are relative and work under a GitHub Pages repository subpath. Open index.html directly for offline reading, or serve this folder with any static server.

## GitHub Pages

1. Upload this folder's contents to the root of a GitHub repository.
2. In Settings → Pages choose Deploy from a branch, select your branch and /(root), then Save.
3. Visit the URL GitHub provides. No build, package installation, or secret is required.

## Audio

The audio player and audio controls have been removed. No recording is bundled or played.

## Content and typography

approved-manuscript.txt preserves all six article source texts, including reporter asides. content-audit.json records counts: joint interview 21 questions, solos 6 each.
